# Hayverse — что умеет приложение

Пользовательский гид по тому, что реально работает в приложении прямо сейчас
и как этим пользоваться. Это **не** архитектурный документ — про «как это
устроено внутри» см. `CLAUDE.md`/`DESIGN.md`/`DECISIONS.md`. «Каталог нод» в
`DESIGN.md` — это план на будущее (классификация A/B/C), а не список того, что
уже есть; актуальный список — здесь, в разделе «Каталог нод» ниже.

> **Этот документ должен обновляться в том же PR**, где меняется
> пользовательская функциональность — см. правило в `apps/web/CLAUDE.md`.

---

## Что это такое

Hayverse — нодовый редактор сцен: вы собираете **сцену** из нод-объектов
(персонаж, локация, одежда и т.д.), соединяете их пины друг с другом и с
генеративными AI-нодами, и получаете на выходе изображение или видео сцены.
Несколько сцен подряд образуют фильм — за это отвечает Таймлайн внизу экрана.

## Основы работы с графом

- **Добавить ноду** — двойной клик по пустому месту холста открывает окно
  поиска нод с фильтром по категориям (Сущности, Нарратив, Pinterest,
  Higgsfield AI, Gemini AI, Утилиты, Вывод).
- **Соединить ноды** — потяните за точку (пин) одной ноды к пину другой. Пины
  бывают четырёх типов — **Image**, **Video**, **Audio**, **Text** — и
  соединяются только пин-в-пин одного типа (картинку нельзя подключить к
  текстовому входу). Цвет точки подсказывает тип.
- Если у входного пина уже было соединение, новое **заменяет** старое — один
  вход не может слушать двух источников одновременно. Выход, наоборот, можно
  протянуть сразу на много входов.
- **Переименовать ноду** — двойной клик по заголовку.
- **Меню ноды** (⋮ в заголовке): **Дублировать** (или Ctrl/Cmd+C →
  Ctrl/Cmd+V, пока нода выделена), **Показать JSON превью** (только у
  «богатых» сущностей и «Выходной Сцены» — сырые параметры ноды одной
  строкой), **Удалить** (или клавиша Delete).
- **↔ в заголовке ноды** — показать подписи пинов постоянно, а не только по
  наведению.
- **Прогнать граф** (кнопка в шапке) — пересчитать весь граф целиком,
  **включая** платные/медленные AI-ноды. Автопересчёт при обычном
  редактировании параметров тоже идёт постоянно, но AI-генерацию сам по себе
  никогда не запускает — только эта кнопка или ▶ на самой AI-ноде.
- Поле с пином рядом (например «Промпт» у Gemini-нод) само становится
  недоступным для ручного ввода и показывает живое значение с подключённой
  ноды, как только вы что-то в этот пин подключили — с подсказкой
  «Подключено к входному пину».

## Каталог нод

### Сущности

Все ноды в этой группе (кроме «Раскадровки») делят одну и ту же механику —
фотогалерею и систему пресетов (см. ниже).

| Нода      | Что это                                                                                     |
| --------- | ------------------------------------------------------------------------------------------- |
| Персонаж  | Повторяющийся персонаж: внешность, координаты рождения/смерти/текущие, сюжетная арка, фото. |
| Локация   | Место: интерьер/экстерьер, погода, время суток, координаты и радиус зоны.                   |
| Здание    | Здание как отдельная сущность.                                                              |
| Одежда    | Предмет одежды/костюма, сезонный тег.                                                       |
| Искусство | Арт-объект.                                                                                 |
| Мебель    | Предмет мебели/реквизита.                                                                   |

### Нарратив

| Нода        | Что это                                                                       |
| ----------- | ----------------------------------------------------------------------------- |
| Музыка      | Музыкальная тема; фиксированный выходной пин Audio.                           |
| Сценарий    | Текст сценария/диалога; выходной пин Text.                                    |
| Раскадровка | Раскадровка кадра; выходной пин Image. Единственная сущность без фотогалереи. |
| Транспорт   | Транспортное средство.                                                        |
| Мизансцена  | Расстановка персонажей в кадре (кто где стоит), схемы расстановки.            |

### Pinterest

| Нода            | Что это                                                                                                                                                     |
| --------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Pinterest Доска | Отдаёт одно изображение-пин с подключённого через ваш аккаунт Pinterest-борда. Без входа в аккаунт показывает набор моковых картинок вместо реальных досок. |

### Higgsfield AI

| Нода              | Что это                                                                        |
| ----------------- | ------------------------------------------------------------------------------ |
| Higgsfield Soul   | Стилизованный портрет из референса лица + промпта стиля.                       |
| Higgsfield Motion | Применяет пресет движения камеры (орбита, наезд и т.д.) к кадру, отдаёт видео. |
| Higgsfield Speak  | Липсинк кадра под речь/аудио.                                                  |

> **Важно:** без настроенного на сервере ключа Higgsfield-ноды либо просто
> пропускают картинку насквозь без изменений (Soul/Motion, с плашкой
> «симуляция»), либо вообще не имеют реального API (Speak — всегда
> симуляция, вне зависимости от ключа). Пока ключ не настроен на конкретном
> деплое, эта группа нод — по сути демо-заглушка.

### Gemini AI

Все шесть нод хранят **историю генераций** — см. отдельный раздел ниже.

| Нода          | Что это                                                                       |
| ------------- | ----------------------------------------------------------------------------- |
| Gemini Text   | Генерация текста по промпту.                                                  |
| Gemini Vision | Описание/анализ картинки по текстовому запросу.                               |
| Imagen 4      | Генерация изображения по тексту.                                              |
| Veo Video     | Генерация видео по тексту (+ опционально референсный кадр).                   |
| Nano Banana   | Генерация/редактирование изображения по промпту и до 14 референсных картинок. |
| Lyria Music   | Генерация музыки/аудио по тексту.                                             |

Без настроенного ключа Gemini на сервере текстовые ноды возвращают заметно
фейковое значение вида `[Gemini mock] ваш промпт`, а генерация
картинки/видео/аудио просто ничего не выдаёт.

### Утилиты

| Нода             | Что это                                                                                                                   |
| ---------------- | ------------------------------------------------------------------------------------------------------------------------- |
| Текстовый Промпт | Свободный текстовый сниппет; можно добавлять ещё текстовые поля-пины (до 8), которые склеятся через запятую в один выход. |

### Вывод

| Нода           | Что это                                                                                                                                                                                                                                        |
| -------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Выходная Сцена | Финальная нода сцены: принимает Visual Render (Image) и Motion Render (Video), хранит метаданные сцены (название/начало/длительность/дорожка/обложка/рендер-движок) и настройки «Арки». Ровно одна на сцену — удалили её, удалилась вся сцена. |

## Особые правила подключения пинов

- **Gemini Vision** — два входа: Image (обязателен для запуска) и Query
  (Text, необязателен — без подключения используется собственное текстовое
  поле «Запрос к изображению»).
- **Nano Banana** — первый пин всегда «Промпт» (Text), дальше можно кнопкой
  ➕ добавлять пины «Референсное изображение N» (Image), максимум 14.
- **Veo Video** — «Промпт» (Text) + необязательный «Референсное изображение»
  (Image) как стартовый кадр.
- **Текстовый Промпт** — первый пин «Text 1» несъёмный, остальные добавляются
  и удаляются по одному (крестик при наведении).
- **Фото сущностей** — у каждого фото в галерее свой собственный выходной
  пин Image («Photo 1», «Photo 2», ...). Удаление одного фото не рвёт
  соединения остальных.
- «Богатые» сущности (Персонаж, Локация, Мизансцена) дополнительно всегда
  имеют выходы **Description** (Text, содержимое поля «Доп. описание») и
  **JSON** (Text, полный дамп параметров).

## Пресеты

У каждой сущности (кроме Раскадровки) рядом с выпадающим списком «Выбрать
пресет...» есть кнопка сохранения (иконка дискеты):

- Клик по «Выбрать пресет...» открывает окно со всеми сохранёнными пресетами
  этого типа сущности (фото + название), выбор карточки применяет её
  параметры к ноде.
- Кнопка сохранения активна (подсвечена), только если в ноде есть
  несохранённые изменения относительно уже сохранённого пресета (или пресет
  ещё не сохранён вовсе). Сохранение — это **явное** действие: правка полей
  ноды сама по себе никогда не перезаписывает общий пресет и не трогает
  другие ноды, где этот же пресет уже выбран.
- Сохранить нельзя, если не заполнены обязательные поля — как минимум
  **Имя** и хотя бы одно **Фото**; у Персонажа ещё и **Возраст** (10–90).
  Кнопка покажет во всплывающей подсказке, чего не хватает.
- Пресеты общие для всего типа сущности, а не привязаны к конкретной сцене —
  сохранённого «Персонажа» можно выбрать в любой другой сцене.

## Фотогалерея и обложка

У каждой сущности с фотографиями — три способа добавить фото:

1. **Загрузить** — с диска, можно сразу несколько файлов.
2. **Выбрать из медиатеки** — открывает общую Медиатеку (см. ниже).
3. **Сгенерировать** (иконка волшебной палочки) — пока доступно только у
   Персонажа: строит промпт из имени/возраста/эмоции/причёски/одежды и
   отправляет уже загруженные фото персонажа как референс в Nano Banana,
   добавляя результат новым фото.

Максимум 10 фото на сущность. Последнее добавленное фото автоматически
становится **обложкой** — большим превью сверху с перелистыванием
(стрелки/счётчик), под ним лента миниатюр. Клик по миниатюре или
перелистывание большого превью — это и есть смена обложки, отдельной кнопки
«сделать обложкой» нет. Удаление фото (корзина на превью) рвёт соединения
только его собственного выходного пина.

У «Выходной Сцены» — своя отдельная обложка (одна картинка, не галерея), тем
же способом «Загрузить»/«Выбрать из медиатеки»: это она показывается
карточкой сцены в Таймлайне.

## Медиатека

Общее хранилище файлов, открывается кнопкой «Выбрать из медиатеки» из
фотогалереи сущности или из поля обложки сцены. Две вкладки:

- **Загруженные** — всё, что вы явно загрузили с диска.
- **Сгенерированные** — всё, что появилось через AI-генерацию (фото
  персонажа, история генераций Gemini-нод и т.д.).

Выбор карточки сразу подставляет файл в то поле, откуда медиатека была
открыта — это одиночный выбор, без множественного выделения.

> Открыть медиатеку можно только войдя в аккаунт — без входа кнопка
> неактивна с подсказкой «Войдите, чтобы открыть медиатеку».

## История генераций (Gemini-ноды)

У всех шести Gemini-нод после первой генерации появляется навигация по
истории — у картинки/видео это перелистывание поверх самого превью
(стрелки, счётчик, корзина), у аудио и текста — тонкая полоска с теми же
кнопками над плеером/текстом.

- Каждый клик по ▶ на самой ноде (или «Прогнать граф») добавляет новый
  результат в историю и сразу переключает на него.
- **Перемотка назад/вперёд** по истории не только меняет показанный
  результат, но и **откатывает параметры ноды** к тем, что реально привели к
  этому результату — включая текст промпта, даже если сейчас в промпт
  подключена другая нода (показывается именно тот текст, что был на момент
  генерации).
- История хранит до 20 последних результатов на ноду, старые вытесняются
  новыми.
- Корзина удаляет запись из истории конкретной ноды — сам файл в Медиатеке
  при этом не удаляется.
- Сохранение результата в историю требует входа в аккаунт (см. «Аккаунт»)
  — без входа генерация всё равно покажется в ноде, но не сохранится и
  пропадёт после перезагрузки страницы.

## Таймлайн: Сцены, Сеть судеб, Scene Arc

Таймлайн внизу экрана — это не часть графа, а отдельный слой поверх ваших
сцен. У него три вкладки:

- **Сцены** — две дорожки с карточками сцен (обложка + название), линейка,
  плейхед. Позиция и длительность карточки на дорожке берутся напрямую из
  полей «Начало (сек)»/«Длительность (сек)»/«Дорожка» самой ноды «Выходная
  Сцена» — перетаскивания карточек мышью нет, редактируется через параметры
  ноды. Кнопка ➕ добавляет новую пустую сцену, начинающуюся сразу после
  последней на первой дорожке.
- **Сеть судеб** — визуализация того, в каких сценах появляется каждый
  персонаж (по одному и тому же сохранённому пресету персонажа), в виде
  цветных нитей, сходящихся в «синапсы» там, где несколько персонажей
  встречаются в одной сцене. Можно кликнуть по персонажу, чтобы выделить
  только его нить.
- **Scene Arc** — сюжетные метаданные конкретной сцены: матрица конфликта и
  чек-лист «открытий лор-линий». (Ещё два похожих поля — эмоциональный тренд
  и уровень напряжения/ритм — на самом деле находятся не здесь, а в
  параметрах самой ноды «Выходная Сцена», в категории «Арка».)

Удаление сцены происходит через удаление её ноды «Выходная Сцена» — не
отдельной командой в Таймлайне.

Кнопки воспроизведения — play/pause (или пробел), скорость (0.5×–2×),
«Стыковка сцен» (схлопнуть пустые промежутки между сценами при
проигрывании), «Автомонтаж». Отдельное плавающее окно **Montage Monitor**
(кнопка с телевизором) показывает актуальный рендер той сцены, что сейчас
находится под плейхедом — вне зависимости от того, какая сцена открыта в
редакторе.

## Карта мира

Кнопка с глобусом в Таймлайне открывает 3D-карту с текущими координатами
персонажей (пульсирующие точки) и локаций (полупрозрачный круг радиуса зоны)
активной сцены — только для нод, где координаты реально заданы.

## Аккаунт

Вход не обязателен для основной работы — граф, ноды, сцены, пресеты,
Таймлайн, Карта мира и даже сами AI-генерации работают без входа. Вход
нужен конкретно для:

- загрузки файлов и открытия Медиатеки;
- генерации фото персонажа через AI;
- **сохранения** результатов AI-генерации в историю ноды (без входа
  результат виден, но не переживёт перезагрузку страницы);
- подключения Pinterest-аккаунта (профиль → вкладка «Интеграции»).

Профиль (кнопка «Войти»/иконка профиля в шапке) также показывает вкладку
«Команда» — список авторов проекта.
