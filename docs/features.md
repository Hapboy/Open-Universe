# Hayverse — что умеет приложение

Пользовательский гид по тому, что реально работает в приложении прямо сейчас
и как этим пользоваться. Это **не** архитектурный документ — про «как это
устроено внутри» см. `CLAUDE.md`/`DESIGN.md`/`DECISIONS.md`. «Каталог нод» в
`DESIGN.md` — это план на будущее (классификация A/B/C), а не список того, что
уже есть; актуальный список — здесь, в разделе «Каталог нод» ниже.

> **Этот документ должен обновляться в том же PR**, где меняется
> пользовательская функциональность — см. правило в `apps/web/CLAUDE.md`.

---

## Что это такое

Hayverse — нодовый редактор сцен: вы собираете **сцену** из нод-объектов
(персонаж, локация, одежда и т.д.), соединяете их пины друг с другом и с
генеративными AI-нодами, и получаете на выходе изображение или видео сцены.
Несколько сцен подряд образуют фильм — за это отвечает Таймлайн внизу экрана.

## Основы работы с графом

- **Добавить ноду** — двойной клик по пустому месту холста открывает окно
  поиска нод с фильтром по категориям (Сущности, Нарратив, Pinterest,
  Higgsfield AI, Gemini AI, Утилиты, Вывод).
- **Соединить ноды** — потяните за точку (пин) одной ноды к пину другой. Пины
  бывают четырёх типов — **Image**, **Video**, **Audio**, **Text** — и
  соединяются только пин-в-пин одного типа (картинку нельзя подключить к
  текстовому входу). Цвет точки подсказывает тип — кроме пинов, привязанных к
  конкретной сущности (именной пин каждой сущности и пины сущностей у
  «Выходной Сцены»), у них свой цвет по типу сущности, см. «Особые правила
  подключения пинов» ниже. Линия соединения красится в цвет ноды-источника.
- Если у входного пина уже было соединение, новое **заменяет** старое — один
  вход не может слушать двух источников одновременно. Выход, наоборот, можно
  протянуть сразу на много входов.
- **Переименовать ноду** — двойной клик по заголовку.
- **Меню ноды** (⋮ в заголовке): **Дублировать** (или Ctrl/Cmd+C →
  Ctrl/Cmd+V, пока нода выделена), **Показать JSON превью** (только у
  «богатых» сущностей — Персонаж/Локация/Мизансцена — сырые параметры ноды
  одной строкой), **Удалить** (или клавиша Delete). У «Выходной Сцены» меню
  нет вовсе — она создаётся автоматически и не дублируется и не удаляется
  с холста, см. «Таймлайн: Сцены, Сеть судеб, Scene Arc» ниже.
- **↔ в заголовке ноды** — показать подписи пинов постоянно, а не только по
  наведению.
- **Прогнать граф** (кнопка в шапке) — пересчитать весь граф целиком,
  **включая** платные/медленные AI-ноды. Автопересчёт при обычном
  редактировании параметров тоже идёт постоянно, но AI-генерацию сам по себе
  никогда не запускает — только эта кнопка или ▶ на самой AI-ноде.
- Поле с пином рядом (например «Промпт» у Gemini-нод) само становится
  недоступным для ручного ввода и показывает живое значение с подключённой
  ноды, как только вы что-то в этот пин подключили — с подсказкой
  «Подключено к входному пину».
- **Отменить/повторить** — Ctrl/Cmd+Z отменяет последнее действие в графе
  (правку параметра, перемещение ноды, удаление, соединение/разъединение,
  дублирование, применение пресета и т.д.), Ctrl/Cmd+Shift+Z повторяет
  отменённое. Правка текстового поля или перетаскивание ноды считаются одним
  действием целиком, а не отменяются по символу/пикселю. История своя у
  каждой сцены и не переживает перезагрузку страницы. Не работает, пока
  курсор стоит в текстовом поле — там Ctrl+Z отменяет ввод текста обычным
  образом браузера.

## Каталог нод

### Сущности

Все ноды в этой группе (кроме «Раскадровки») делят одну и ту же механику —
фотогалерею и систему пресетов (см. ниже).

| Нода      | Что это                                                                                     |
| --------- | ------------------------------------------------------------------------------------------- |
| Персонаж  | Повторяющийся персонаж: внешность, координаты рождения/смерти/текущие, сюжетная арка, фото. |
| Локация   | Место: интерьер/экстерьер, погода, время суток, координаты и радиус зоны.                   |
| Здание    | Здание как отдельная сущность.                                                              |
| Одежда    | Предмет одежды/костюма, сезонный тег.                                                       |
| Искусство | Арт-объект.                                                                                 |
| Мебель    | Предмет мебели/реквизита.                                                                   |

### Нарратив

| Нода        | Что это                                                                       |
| ----------- | ----------------------------------------------------------------------------- |
| Музыка      | Музыкальная тема; фиксированный выходной пин Audio.                           |
| Сценарий    | Текст сценария/диалога; выходной пин Text.                                    |
| Раскадровка | Раскадровка кадра; выходной пин Image. Единственная сущность без фотогалереи. |
| Транспорт   | Транспортное средство.                                                        |
| Мизансцена  | Расстановка персонажей в кадре (кто где стоит), схемы расстановки.            |

### Pinterest

| Нода            | Что это                                                                                                                                                     |
| --------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Pinterest Доска | Отдаёт одно изображение-пин с подключённого через ваш аккаунт Pinterest-борда. Без входа в аккаунт показывает набор моковых картинок вместо реальных досок. |

### Higgsfield AI

| Нода              | Что это                                                                        |
| ----------------- | ------------------------------------------------------------------------------ |
| Higgsfield Soul   | Стилизованный портрет из референса лица + промпта стиля.                       |
| Higgsfield Motion | Применяет пресет движения камеры (орбита, наезд и т.д.) к кадру, отдаёт видео. |
| Higgsfield Speak  | Липсинк кадра под речь/аудио.                                                  |

> **Важно:** без настроенного на сервере ключа Higgsfield-ноды либо просто
> пропускают картинку насквозь без изменений (Soul/Motion, с плашкой
> «симуляция»), либо вообще не имеют реального API (Speak — всегда
> симуляция, вне зависимости от ключа). Пока ключ не настроен на конкретном
> деплое, эта группа нод — по сути демо-заглушка.

### Gemini AI

Все шесть нод хранят **историю генераций** — см. отдельный раздел ниже.

| Нода          | Что это                                                                       |
| ------------- | ----------------------------------------------------------------------------- |
| Gemini Text   | Генерация текста по промпту.                                                  |
| Gemini Vision | Описание/анализ картинки по текстовому запросу.                               |
| Imagen 4      | Генерация изображения по тексту.                                              |
| Veo Video     | Генерация видео по тексту (+ опционально референсный кадр).                   |
| Nano Banana   | Генерация/редактирование изображения по промпту и до 14 референсных картинок. |
| Lyria Music   | Генерация музыки/аудио по тексту.                                             |

Без настроенного ключа Gemini на сервере текстовые ноды возвращают заметно
фейковое значение вида `[Gemini mock] ваш промпт`, а генерация
картинки/видео/аудио просто ничего не выдаёт.

### Утилиты

| Нода             | Что это                                                                                                                   |
| ---------------- | ------------------------------------------------------------------------------------------------------------------------- |
| Текстовый Промпт | Свободный текстовый сниппет; можно добавлять ещё текстовые поля-пины (до 8), которые склеятся через запятую в один выход. |

### Вывод

| Нода           | Что это                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| -------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Выходная Сцена | Финальная нода сцены и хаб генерации: принимает входы от сущностей сцены (Персонаж/Локация/Мебель/...), сама составляет промпт и генерирует кадр (Nano Banana) и видео (Veo) — см. «Генерация сцены прямо в Выходной Сцене» ниже. Также хранит метаданные сцены (название/начало/длительность/дорожка/обложка) и настройки «Арки». Ровно одна на сцену, создаётся автоматически — не дублируется и не удаляется с холста, только вместе со всей сценой через Таймлайн (см. ниже). |

## Особые правила подключения пинов

- **Gemini Vision** — два входа: Image (обязателен для запуска) и Query
  (Text, необязателен — без подключения используется собственное текстовое
  поле «Запрос к изображению»).
- **Nano Banana** — первый пин всегда «Промпт» (Text), дальше можно кнопкой
  ➕ добавлять пины «Референсное изображение N» (Image), максимум 14.
- **Veo Video** — «Промпт» (Text) + необязательный «Референсное изображение»
  (Image) как стартовый кадр.
- **Текстовый Промпт** — первый пин «Text 1» несъёмный, остальные добавляются
  и удаляются по одному (крестик при наведении).
- **Фото сущностей** — у каждого фото в галерее свой собственный выходной
  пин Image («Photo 1», «Photo 2», ...). Удаление одного фото не рвёт
  соединения остальных.
- Все типы сущностей имеют выходы **Description** (Text) и **пин самой
  сущности** (Text, заполненные параметры сущности плюс включённые фото с их
  описаниями; служебное — выбранный пресет, индекс обложки, настройки
  собственной генерации — в него не уходит) — это то, что подключается
  во входные пины «Выходной Сцены» (см. ниже). Этот пин подписан именем
  своего типа сущности («Персонаж», «Мизансцена», ...) — тем же словом, что
  и входной пин «Выходной Сцены», в который он идёт («Мизансцена 1»), так что
  оба конца провода называются одинаково. У «богатых» сущностей
  (Персонаж, Локация, Мизансцена) Description дополнительно редактируется
  через собственное поле «Доп. описание» в раскрывающейся боковой панели.
  Пин сущности покрашен в собственный цвет своего типа (тот же, что
  и левая цветная рамка ноды); Description остаётся обычного цвета типа Text
  — так на глаз видно, какой именно пин что несёт. У каждого из 11 типов
  сущностей (Персонаж, Локация, Здание, Одежда, Искусство, Мебель, Музыка,
  Сценарий, Раскадровка, Транспорт, Мизансцена) свой уникальный цвет.
- **Выходная Сцена** — два фиксированных пина Visual Render (Image)/Motion
  Render (Video) для ручного подключения готового кадра/видео извне (если
  подключены — имеют приоритет над встроенной генерацией), плюс отдельная
  кнопка «+ <Тип>» на каждый тип сущности во вкладке «Сущности» её
  параметров — добавляет очередной пронумерованный пин («Персонаж 1»,
  «Персонаж 2», ...), тоже покрашенный в цвет своего типа сущности. Лишний
  пин убирается наведением на него на холсте и кликом по крестику —
  отдельного списка «Подключённые пины» в параметрах для этого нет.

## Генерация сцены прямо в Выходной Сцене

Раньше кадр и видео собирались вручную: отдельная нода Nano Banana → отдельная
нода Veo → результат вручную подключался в «Выходную Сцену». Теперь эта
генерация встроена прямо в «Выходную Сцену» — отдельные ноды Nano
Banana/Veo Video из группы «Gemini AI» по-прежнему доступны для ручных/
нестандартных сценариев, но для типового пути они не нужны.

Во параметрах «Выходной Сцены»:

1. **Вкладка «Сущности»** — подключите к ноде персонажей, локацию, мебель и
   т.д. (см. «Особые правила подключения пинов» выше).
2. Переключатель **«Составлять промпт через LLM»** — определяет, как из
   подключённых сущностей + настроек «Арки» получается текстовый промпт:
   включён — один вызов текстовой модели превращает JSON сущностей в связный
   текст на естественном языке; выключен — сериализованный JSON сущностей
   отправляется как промпт напрямую, без вызова модели. По умолчанию
   **выключен** (лишнего вызова модели не происходит, пока его не попросят).
   Один переключатель сразу на обе стадии (Картинка и Видео); у Персонажа —
   ровно такой же, см. «Генерация фото персонажа».
3. Поле **«Дополнительное описание»** (в боковой панели, см. пункт 5) — свой
   свободный текст, который добавляется **перед** промптом, собранным из
   сущностей, у обеих стадий сразу. Тот же приём, что у «Доп. описание» на
   «богатых» сущностях, только результат не отдельный выход, а прямая
   добавка к итоговому промпту.
4. Сегментированный переключатель **«Картинка / Видео»** и превью выбранной
   стадии закреплены **в самом верху ноды**, над поиском и категориями — их
   видно всегда, независимо от того, открыта категория «Генерация» или нет.
   Переключатель выбирает, какая из двух стадий показана: у каждой своя
   история кадров/видео с перелистыванием и свои параметры модели (те же
   поля, что у отдельных нод Nano Banana/Veo Video, внутри категории
   «Генерация»).
    - Кнопка запуска — **▶ в шапке ноды**, там же, где у отдельных Gemini-нод.
      Она относится к выбранной стадии и тоже работает при закрытой категории.
    - **Картинка** — ▶ составляет промпт, собирает референсные фото со всех
      подключённых сущностей и вызывает Nano Banana. Результат сразу
      становится текущим выбранным кадром; при желании его можно заменить на
      любое изображение из Медиатеки — кнопка на самом превью (или клик по
      пустому плейсхолдеру, если кадров ещё нет). Отдельного шага
      «подтверждения» нет, любой выбранный файл сразу считается готовым
      кадром для следующей стадии. Поле «Сид (seed)» здесь поддерживает
      копирование и кнопку «Reroll» — см. «Сид генерации и повтор с
      вариацией» ниже.
    - **Видео** — ▶ доступна только после того, как на вкладке «Картинка»
      выбран кадр; она вызывает Veo с этим кадром как референсом. Результат
      так же можно заменить через Медиатеку. Сид здесь недоступен (как и у
      отдельной ноды Veo Video — см. ниже).
    - Если у ноды вручную подключён пин Visual Render (для Картинки) или
      Motion Render (для Видео) — соответствующая вкладка отключается: пин
      имеет приоритет, встроенная генерация для этой стадии недоступна (▶
      гаснет), пока он подключён.
5. Кнопка со значком заметок в шапке ноды (та же, что открывает «Доп.
   описание» у сущностей) открывает боковую панель — сверху редактируемое
   поле «Дополнительное описание» (пункт 3), под ним **текст последнего
   составленного промпта** только для чтения, той стадии (Картинка/Видео),
   что выбрана переключателем выше. Полезно, чтобы сравнить, что реально
   получается в режимах «через LLM» и «сырой JSON», и как на него влияет
   дополнительное описание. Эта панель и режим «показать подписи пинов»
   (кнопка ↔) теперь можно открыть одновременно — нода станет шире, чтобы
   уместить оба.

## Пресеты

У каждой сущности (кроме Раскадровки) рядом с выпадающим списком «Выбрать
пресет...» есть кнопка сохранения (иконка дискеты):

- Клик по «Выбрать пресет...» открывает окно со всеми сохранёнными пресетами
  этого типа сущности (фото + название), выбор карточки применяет её
  параметры к ноде.
- Кнопка сохранения активна (подсвечена), только если в ноде есть
  несохранённые изменения относительно уже сохранённого пресета (или пресет
  ещё не сохранён вовсе). Сохранение — это **явное** действие: правка полей
  ноды сама по себе никогда не перезаписывает общий пресет и не трогает
  другие ноды, где этот же пресет уже выбран.
- Сохранить нельзя, если не заполнены обязательные поля — как минимум
  **Имя** и хотя бы одно **Фото**; у Персонажа ещё и **Возраст** (10–90).
  Кнопка покажет во всплывающей подсказке, чего не хватает.
- Пресеты общие для всего типа сущности, а не привязаны к конкретной сцене —
  сохранённого «Персонажа» можно выбрать в любой другой сцене.

## Фотогалерея и обложка

У каждой сущности с фотографиями — два способа добавить фото, обе кнопки
живут **на самом превью**, в правом верхнем углу:

1. **Загрузить** (стрелка вверх) — с диска, можно сразу несколько файлов.
2. **Выбрать из медиатеки** (плюс с картинкой) — открывает общую Медиатеку
   (см. ниже).

Пока фотографий нет, превью показывается как **пустая рамка-плейсхолдер** с
подсказкой «Нет фото — загрузите или выберите из медиатеки»; клик по ней
открывает Медиатеку. Так сразу видно, куда добавляются фото, даже у только
что созданной ноды.

Персонаж умеет ещё и генерировать фото сам — но это отдельный блок
«Генерация фото персонажа» (см. ниже), результат попадает в галерею только
когда вы его примете.

Максимум 10 фото на сущность (по достижении лимита обе кнопки добавления
гаснут). Последнее добавленное фото автоматически становится **обложкой** —
большим превью сверху с перелистыванием (стрелки/счётчик), под ним лента
миниатюр. Клик по миниатюре или перелистывание большого превью — это и есть
смена обложки, отдельной кнопки «сделать обложкой» нет. Удаление фото
(корзина на превью) рвёт соединения только его собственного выходного пина.
Отдельной строки «Фото ...» в параметрах больше нет — счётчик на превью и
лента миниатюр показывают то же самое.

Каждое фото можно **описать и выключить**:

- **Что на фото** и **Роль фото** (лицо / в полный рост / профиль / одежда /
  деталь / окружение) — поля под большим превью, относятся к тому фото, на
  котором сейчас стоит превью. Это описание уходит в именной выход сущности
  и, значит, в промпт любой генерации, которая её использует — так модели
  можно объяснить, что второе фото это референс одежды, а не лица.
- **Глазок на миниатюре** — исключает фото из именного выхода сущности и из списка
  референсов для генерации; исключённое фото становится приглушённым в ленте
  миниатюр. Свой выходной пин Image у такого фото остаётся — ручное
  подключение это осознанное действие и продолжает работать.

У «Выходной Сцены» — своя отдельная обложка (одна картинка, не галерея), тем
же способом «Загрузить»/«Выбрать из медиатеки»: это она показывается
карточкой сцены в Таймлайне.

## Медиатека

Общее хранилище файлов, открывается кнопкой «Выбрать из медиатеки» — она
живёт на превью (фотогалерея сущности, варианты генерации персонажа,
кадр/видео «Выходной Сцены») либо в поле обложки сцены. Пустое превью само
работает такой кнопкой. Две вкладки:

- **Загруженные** — всё, что вы явно загрузили с диска.
- **Сгенерированные** — всё, что появилось через AI-генерацию (фото
  персонажа, история генераций Gemini-нод, кадры/видео «Выходной Сцены» и
  т.д.).

Выбор карточки сразу подставляет файл в то поле, откуда медиатека была
открыта — это одиночный выбор, без множественного выделения.

> Открыть медиатеку можно только войдя в аккаунт — без входа кнопка
> неактивна с подсказкой «Войдите, чтобы открыть медиатеку».

## Генерация фото персонажа

У Персонажа своя категория параметров **«Генерация»** (рядом с «Общие»,
«Рождение», «Арка», «Стиль») — те же поля, что у ноды Nano Banana (модель,
соотношение сторон, разрешение, сид с «Reroll»), плюс тот же переключатель
**«Составлять промпт через LLM»**, что и у «Выходной Сцены»: включён — промпт
пишет текстовая модель, выключен (по умолчанию) — уходит JSON параметров, без
лишнего вызова.

В промпт попадает только то, что описывает **внешность**: имя, возраст,
эмоция, стилист, причёска, татуировки, аксессуары, одежда, цвет, описания
фото и «Доп. описание» из боковой панели. Арка, даты жизни и координаты
сознательно не попадают — в промпте портрета это шум. Сам составленный промпт
видно в той же боковой панели (кнопка с блокнотом в шапке ноды): с выключенным
переключателем он пересчитывается на глазах, с включённым — показывается тот,
что реально ушёл при последней генерации.

Кнопка запуска — **▶ в шапке ноды**, там же, где у Nano Banana и остальных
AI-нод; она работает независимо от того, открыта категория «Генерация» или
нет. Под категорией остаются только настройки модели и переключатель LLM.

Референсами идут включённые фото персонажа (см. «Фотогалерея и обложка»).
Результаты **не попадают** в галерею сами: они складываются в свою историю с
перелистыванием — блок **«Варианты генерации»** сразу под фотогалереей, тоже
вне категорий, так что сгенерированное видно всегда. Кнопка **✓ «Принять в
фото»** (на самом превью варианта, рядом с корзиной и «Reroll») добавляет
текущий вариант в галерею персонажа. Обложка при этом не меняется (если
галерея не была пустой), корзина в истории удаляет вариант, не трогая
галерею. Туда же можно подложить картинку из Медиатеки — кнопкой на превью.
Одна генерация может вернуть сразу несколько вариантов — все они попадут в
историю, а перелистывание вернёт и параметры, которыми они были сделаны.

## История генераций (Gemini-ноды)

У всех шести Gemini-нод после первой генерации появляется навигация по
истории — у картинки/видео это перелистывание поверх самого превью
(стрелки, счётчик, корзина), у аудио и текста — тонкая полоска с теми же
кнопками над плеером/текстом. У встроенной генерации «Выходной Сцены» такой
браузируемой истории нет — вместо неё каждый результат сразу уходит в
Медиатеку (вкладка «Сгенерированные»), откуда его в любой момент можно
выбрать заново кнопкой «Выбрать из медиатеки».

- Каждый клик по ▶ на самой ноде (или «Прогнать граф») добавляет новый
  результат в историю и сразу переключает на него.
- **Перемотка назад/вперёд** по истории не только меняет показанный
  результат, но и **откатывает параметры ноды** к тем, что реально привели к
  этому результату — включая текст промпта, даже если сейчас в промпт
  подключена другая нода (показывается именно тот текст, что был на момент
  генерации).
- История хранит до 20 последних результатов на ноду, старые вытесняются
  новыми.
- Корзина удаляет запись из истории конкретной ноды — сам файл в Медиатеке
  при этом не удаляется.
- Генерация требует входа в аккаунт (см. «Аккаунт») — без входа кнопка ▶
  открывает окно входа вместо запуска.

## Сид генерации и повтор с вариацией

У каждого работающего поля **«Сид (seed)»** — иконка копирования рядом,
копирует текущее значение в буфер обмена. Сид реально влияет на результат
только у **Nano Banana** и **Lyria Music** (включая вкладку «Картинка» у
«Выходной Сцены», которая использует ту же модель) — у них рядом с полем
есть ещё и кнопка-кубик **«Reroll»**: генерирует новый результат с тем же
промптом и остальными параметрами, но сидом, увеличенным на 10000
относительно текущего — то есть узнаваемо похожий, но не идентичный
вариант, а не совсем случайный результат. У **Imagen 4** и **Veo Video**
(и вкладки «Видео» «Выходной Сцены») поле сида недоступно — эти модели
поддерживают сид только через Vertex AI Enterprise, чего нет в этом
браузерном приложении.

Если оставить поле сида пустым и просто нажать «Сгенерировать» —
приложение само подставляет случайное число и сохраняет его в поле, а не
оставляет пустым: так у кнопки «Reroll» всегда есть от чего оттолкнуться,
даже если это самая первая генерация (сама модель никогда не возвращает,
какой сид она выбрала бы на пустом поле).

## Таймлайн: Сцены, Сеть судеб, Scene Arc

Таймлайн внизу экрана — это не часть графа, а отдельный слой поверх ваших
сцен. У него три вкладки:

- **Сцены** — две дорожки с карточками сцен (обложка + название), линейка,
  плейхед. Позиция и длительность карточки на дорожке берутся напрямую из
  полей «Начало (сек)»/«Длительность (сек)»/«Дорожка» самой ноды «Выходная
  Сцена» — перетаскивания карточек мышью нет, редактируется через параметры
  ноды. Кнопка ➕ добавляет новую пустую сцену, начинающуюся сразу после
  последней на первой дорожке.
- **Сеть судеб** — визуализация того, в каких сценах появляется каждый
  персонаж (по одному и тому же сохранённому пресету персонажа), в виде
  цветных нитей, сходящихся в «синапсы» там, где несколько персонажей
  встречаются в одной сцене. Можно кликнуть по персонажу, чтобы выделить
  только его нить.
- **Scene Arc** — сюжетные метаданные конкретной сцены: матрица конфликта и
  чек-лист «открытий лор-линий». (Ещё два похожих поля — эмоциональный тренд
  и уровень напряжения/ритм — на самом деле находятся не здесь, а в
  параметрах самой ноды «Выходная Сцена», в категории «Арка».)

**Удалить сцену** — кликните по её карточке на дорожке (это же и делает её
активной) и нажмите клавишу Delete — появится диалог подтверждения
(«Отмена» / «Удалить», либо просто Esc или клик мимо), поскольку отменить
это действие потом уже нельзя. Нода «Выходная Сцена» на холсте для этого не
трогается — у неё нет ни своего пункта «Удалить», ни клавиши Delete:
единственный способ удалить сцену теперь — отсюда, из Таймлайна.

Кнопки воспроизведения — play/pause (или пробел), скорость (0.5×–2×),
«Стыковка сцен» (схлопнуть пустые промежутки между сценами при
проигрывании), «Автомонтаж». Отдельное плавающее окно **Montage Monitor**
(кнопка с телевизором) показывает актуальный рендер той сцены, что сейчас
находится под плейхедом — вне зависимости от того, какая сцена открыта в
редакторе.

## Карта мира

Кнопка с глобусом в Таймлайне открывает 3D-карту с текущими координатами
персонажей (пульсирующие точки) и локаций (полупрозрачный круг радиуса зоны)
активной сцены — только для нод, где координаты реально заданы.

## Аккаунт

Вход не обязателен для основной работы — граф, ноды, сцены, пресеты,
Таймлайн и Карта мира работают без входа. Вход нужен конкретно для:

- загрузки файлов и открытия Медиатеки;
- **любой AI-генерации**: кнопка ▶ на ноде, «Прогнать граф», генерация
  кадра/видео в «Выходной Сцене» и фото персонажа. Без входа генерация не
  запускается вообще — вместо неё открывается окно входа с подсказкой, что
  результат негде сохранить (раньше вызов к модели уходил, а результат
  терялся при загрузке в хранилище);
- подключения Pinterest-аккаунта (профиль → вкладка «Интеграции»).

Профиль (кнопка «Войти»/иконка профиля в шапке) также показывает вкладку
«Команда» — список авторов проекта.
